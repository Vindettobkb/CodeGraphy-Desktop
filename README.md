## English

**CodeGraphy** is a high-performance local developer tool built to eliminate AI context bloat and model hallucinations. Instead of copying and pasting thousands of raw lines of code into ChatGPT, Claude, or Cursor, CodeGraphy lets you visually map your software architecture on an Obsidian-style living graph, link nodes directly to local source files, and extract surgical context prompts via Python AST pruning.

### 🚀 Download
👉 **[Download CodeGraphy for Windows (.exe)](https://github.com/Vindettobkb/CodeGraphy-Desktop/releases/latest)**

### ✨ Key Features
- **Obsidian-Style Canvas**: Interactive dark graph with fluid physics, floating node dynamics, and expandable topic cards powered by React Flow.
- **Deep AST Extraction**: Strips heavy function and class bodies, keeping only signatures, parameters, return types, and docstrings (saves up to 85% LLM tokens).
- **One-Click IDE Jump**: Deep-link integration opening the exact file and line directly in **PyCharm** or **VS Code**.
- **Integrated AI Assistant**: Slide-out drawer with support for your own API Key (OpenAI / Anthropic / Gemini) and automatic active context injection.
- **100% Local-First & Private**: No cloud databases. State is stored strictly in your local `.archflow/` project directory.

## Русский

**CodeGraphy** — это локальный инструмент для разработчиков, решающий проблему переполнения контекста (Context Bloat) и галлюцинаций нейросетей. Вместо ручного копирования сотен строк кода в ChatGPT или Claude, CodeGraphy позволяет визуализировать архитектуру проекта в виде живого графа в стиле Obsidian, связывать модули с реальными файлами и извлекать компактные, точные промпты через парсинг синтаксического дерева (AST).

### 🚀 Скачать
👉 **[Скачать установщик CodeGraphy для Windows (.exe)](https://github.com/Vindettobkb/CodeGraphy-Desktop/releases/latest)**

### ✨ Главные возможности
- **Интерактивный граф в стиле Obsidian**: Плавная физика связей на темном холсте, покачивание узлов и разворачивание из компактных пилюль в полноценные карточки.
- **Умный AST-парсер**: Вырезает тела функций и методов, оставляя только сигнатуры, типы аргументов и докстринги, экономя до 85% токенов контекстного окна.
- **Мгновенный переход в IDE**: Клик по кнопке открывает нужный файл и нужную строку прямо в запущенном **PyCharm** или **VS Code**.
- **Встроенный AI-чат**: Выезжающая панель ассистента с поддержкой вашего личного API-ключа (OpenAI / Anthropic / Gemini).
- **Полная конфиденциальность (Local-First)**: Никаких внешних серверов. Всё состояние хранится локально в директории `.archflow/` вашего проекта.
